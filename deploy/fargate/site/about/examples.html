Using the TAP service

The service speaks the IVOA Table Access Protocol, so any TAP client works with it. Queries are written in ADQL.

pyvo

What the service holds, then a cone search.

import pyvo
tap = pyvo.dal.TAPService('https://aiab.ipac.caltech.edu/TAP')

# what is here?
for t in tap.search("SELECT table_name, description FROM TAP_SCHEMA.tables WHERE schema_name = 'main'"):
    print(t['table_name'], t['description'])

# AllWISE sources within half a degree of a position
cone = tap.search("""
    SELECT designation, ra, dec, w1mpro, w2mpro
    FROM allwise
    WHERE CONTAINS(POINT('ICRS', ra, dec), CIRCLE('ICRS', 43.457, -73.135, 0.5)) = 1
""").to_table()

That cone returns 15,662 sources. Boxes and polygons work the same way, with BOX and POLYGON in place of CIRCLE.

Cross-match with your own table

Send a table with the query and name it TAP_UPLOAD.name. Any table with positions will do; an astropy table is the simplest. Here, galaxies has columns designation, ra and dec.

match = tap.run_async("""
    SELECT g.designation AS galaxy, w.designation AS wise, w.w1mpro, w.w2mpro
    FROM allwise w, TAP_UPLOAD.mine g
    WHERE CONTAINS(POINT('ICRS', w.ra, w.dec),
                   CIRCLE('ICRS', g.ra, g.dec, 0.000833)) = 1      -- 3 arcsec, written as a number
""", uploads={'mine': galaxies}).to_table()

With 949 uploaded positions against the 58.6 million rows of allwise, this takes about 5 seconds. The table must be sent with the request; an upload given as a URL is refused. An uploaded table may be at most 50 MB and 2,000,000 rows.

astroquery

from astroquery.utils.tap.core import TapPlus
tap = TapPlus(url='https://aiab.ipac.caltech.edu/TAP', verbose=False)

# the brightest SDSS DR16 quasars beyond redshift 5
job = tap.launch_job("""
    SELECT TOP 10 sdss_name, ra, dec, z, psfmag_i
    FROM sdss_dr16q
    WHERE z > 5 AND psfmag_i > 0
    ORDER BY psfmag_i""")
print(job.get_results())

# an asynchronous job:  Chandra sources within 2 degrees of the Orion Nebula
job = tap.launch_job_async("""
    SELECT name, ra, dec, significance
    FROM heasarc_csc
    WHERE CONTAINS(POINT('ICRS', ra, dec), CIRCLE('ICRS', 83.82, -5.39, 2.0)) = 1""")
orion = job.get_results()

curl

# a cone search, answered as CSV
curl -s https://aiab.ipac.caltech.edu/TAP/sync \
     --data-urlencode "LANG=ADQL" --data-urlencode "FORMAT=csv" \
     --data-urlencode "QUERY=SELECT TOP 5 source_id, ra, dec, phot_g_mean_mag FROM gaia_bright
                             WHERE CONTAINS(POINT('ICRS', ra, dec), CIRCLE('ICRS', 83.82, -5.39, 5.0)) = 1
                             ORDER BY phot_g_mean_mag"

# the standard TAP documents:  tables and columns, and what the service can do
curl -s https://aiab.ipac.caltech.edu/TAP/tables

FORMAT may also be votable (the default), ipac, tsv or json.

TOPCAT

In the VO menu choose "Table Access Protocol (TAP) Query", enter the address above as the TAP URL and press "Use Service". The tables and their columns appear on the left; type ADQL below and press "Run Query". A table already loaded in TOPCAT can be used in a query as TAP_UPLOAD.t1.

Sync and async

A synchronous query (/TAP/sync, pyvo's search) keeps the connection open until the answer comes. It must start answering within 60 seconds, or the connection is closed with status 504 while the query runs on to no purpose.

An asynchronous job (/TAP/async, pyvo's run_async or submit_job) is started, polled and fetched, and may take up to 300 seconds. Its result is kept for 7 days. Use it for anything that scans a whole large table, and for uploads of any size.

What a refusal means

What you seeWhy, and what to do
403The request came from outside IPAC and Caltech, which is all the pilot admits. From elsewhere, use the Caltech VPN.
"This archive is paused"The service is switched off outside its hours to save cost. Nothing is lost; ask its administrator to start it.
429, "too many requests in progress"One address may have 6 requests in progress at once. Wait for one to finish.
429, "the most it takes at once"The service is handling 12 requests, from everyone together. Try again in a few seconds.
403, "not accepting requests from this address"The administrator has blocked the address.
An async job fails, "jobs running"One address may have 3 async jobs running, and the service runs 8 in all. Submit it again when one has finished.
429 with a volume and a time to try againOne address is sent at most 20 GB in a day. Ask for fewer columns or rows, or wait the time given.
429, plainMore than 1,000 requests from one address in five minutes. It clears a few minutes after the requests slow down.
504A synchronous query took more than 60 seconds to start answering. Send it as an async job.
An error naming memory or timeA query may use 1 GB of memory and 300 seconds. Select fewer columns, or narrow the search by position.
A result of exactly 2,000,000 rowsThat is the most one query returns. Split the query, by position or by a range of a column.

Worth knowing

  • The radius of a cross-match must be written as a number. CIRCLE('ICRS', g.ra, g.dec, 3.0 / 3600) is refused; write 0.000833.
  • Positions are ra and dec, in degrees, in every table.
  • Each table also carries columns the service adds for its own index: hpx29, aiab_x, aiab_y and aiab_z. They can be ignored.
  • A mistaken column name is answered with the engine's own message, which shows the query as it was rewritten.
  • Column units and descriptions are in /TAP/tables and in TAP_SCHEMA.columns.
