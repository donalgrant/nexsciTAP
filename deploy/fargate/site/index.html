Archive in a Box

A small astronomical archive, run as a pilot at IPAC. It serves catalogs of up to about 100 million rows, with positional search and cross-match against a table of your own, through Firefly in the browser or any TAP client.

Search with FireflyFirefly's front page: searches, sky images, charts, and tables of your own. Browse the catalogsFirefly's TAP panel: pick a table, set a position and constraints, or type ADQL. Query with TAPFrom pyvo, astroquery, TOPCAT or curl. The address and an example are below.

A pilot: open to IPAC and Caltech addresses only, and normally running on weekdays, 07:30 to 19:30 Pacific.

The TAP service

https://aiab.ipac.caltech.edu/TAP
# a cone search, with pyvo
import pyvo
tap = pyvo.dal.TAPService(
    'https://aiab.ipac.caltech.edu/TAP')
cone = tap.search("""
    SELECT designation, ra, dec, w1mpro
    FROM allwise
    WHERE CONTAINS(POINT('ICRS', ra, dec),
          CIRCLE('ICRS', 43.457, -73.135, 0.5)) = 1""")

Limits

  • A synchronous query must start answering within 60 seconds. Send longer ones as async jobs.
  • 300 seconds and 2,000,000 rows per query.
  • 3 async jobs running per client; results are kept 7 days.
  • 20 GB sent to one address in a day.

About

Catalogs are Parquet files in cloud storage, queried in place. The TAP server is NExScI's nexsciTAP with an added engine, and the browser front end is IRSA's Firefly, unmodified. Answers were compared query by query with IRSA's own service.

Archive in a Box is a pilot of IPAC at Caltech. It is built on nexsciTAP, from the NASA Exoplanet Science Institute (NExScI), and on Firefly, from the NASA/IPAC Infrared Science Archive (IRSA).
